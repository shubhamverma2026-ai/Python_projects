# 🤖 Local Llama Chatbot

A simple chatbot made with **Streamlit** and **Llama 3.2** using **Ollama**.

## Requirements

* Python
* Streamlit
* Ollama
* Llama 3.2 model

## Install

```bash
pip install streamlit requests
ollama pull llama3.2
```

## Run

```bash
streamlit run app.py
```

Make sure Ollama is running before starting the app.
