# QR Code Generator

A simple Python program that generates a QR code from text or a URL and saves it as an image.

## Features

- Takes text or a URL from the user
- Generates a QR code
- Saves the QR code as `my_qr_code.png`
- Checks if the user entered empty input

## Requirements

- Python 3.x
- qrcode library

## Installation

Install the required library using:

```bash
pip install qrcode[pil]
