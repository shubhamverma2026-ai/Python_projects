# Image to PDF Converter

A simple Python program that combines multiple images into a single PDF file.

## Features

- Accepts multiple image paths
- Converts images to RGB format
- Combines multiple images into one PDF
- Lets the user choose the PDF file name
- Automatically adds `.pdf` if it is not provided

## Requirements

- Python 3.x
- Pillow library

## Installation

Install the Pillow library:

pip install pillow
