# Currency Converter

A simple Python program that converts an amount from one currency to another using the Frankfurter API.

## Features

- Converts between currencies
- Uses live exchange rates from an API
- Supports USD, INR, and EUR
- Takes amount and currencies from the user
- Displays the converted amount

## Requirements

- Python 3.x
- requests library
- Internet connection
