# WhatsApp Message Automator

A simple Python program that uses PyWhatKit to send an automated WhatsApp message to a specified phone number.

## Features

- Sends a WhatsApp message automatically
- Uses a phone number with country code
- Sends the message multiple times
- Adds a delay between messages
- Prints the message number after each attempt

## Requirements

- Python 3.x
- PyWhatKit library
- Internet connection
- WhatsApp Web
- A WhatsApp account
