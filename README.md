# Modern Calculator

A simple modern calculator application developed using **Python** and **Tkinter**.

## Features

* Basic arithmetic operations: `+`, `-`, `×`, `÷`
* Decimal calculations
* Brackets for expressions
* **Clear** button
* **Backspace** button
* Error handling for invalid expressions
* Options menu with Clear and Exit
* Simple and clean graphical user interface

## Technologies Used

* Python
* Tkinter

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python calculator.py
```

The calculator window will open.

## How It Works

The calculator uses **Tkinter** to create the graphical user interface. Buttons are used to enter numbers and operators into the display. The entered mathematical expression is evaluated when the `=` button is pressed.
