# ✍️ Text to Handwriting Converter

A simple Streamlit app that converts typed text into a handwritten-style image.

URL : https://text2handwriting.streamlit.app/

## Features

* Enter your text
* Convert text into handwriting
* Blue pen-style writing
* Download the handwritten image

## Requirements

* Python
* Streamlit
* Pillow
* `handwriting.ttf`

## Installation

```bash
pip install streamlit pillow
```

## Run the App

```bash
streamlit run app.py
```

## Project Structure

```text
text-to-handwriting/
├── app.py
├── handwriting.ttf
└── README.md
```

## Note

Make sure `handwriting.ttf` is in the same folder as `app.py`.
