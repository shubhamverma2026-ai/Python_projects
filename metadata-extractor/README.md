# Image Metadata Extractor

A simple Python program that extracts basic information and EXIF metadata from an image.

The program also saves the extracted metadata in a text file called `metadata_report.txt`.

## Features

- Shows image file name
- Shows image type
- Shows file size
- Shows image width and height
- Extracts EXIF metadata
- Saves metadata to a text report

## Requirements

- Python 3.x
- Pillow library

## Installation
