# Weather Information

A simple Python program that gets current weather information for a city using the OpenWeatherMap API.

## Features

- Takes city name from the user
- Gets current weather information using an API
- Shows temperature
- Shows humidity
- Shows weather description
- Handles API errors

## Requirements

- Python 3.x
- requests library
- OpenWeatherMap API key
- Internet connection
